## Subir a GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube todo el contenido de esta carpeta manteniendo `assets` junto a `index.html`.
3. En **Settings → Pages**, selecciona `Deploy from a branch`.
4. Elige la rama `main` y la carpeta `/ (root)`.
5. Guarda y espera a que GitHub genere la URL.

La invitación funciona como sitio estático: no necesita instalación ni servidor.
